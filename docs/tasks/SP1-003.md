## Act

### Lessons Learned
- **先研究 sub-skill 內部 API，再寫 orchestrator prompts**：派研究 agent 看 Anthropic skills repo 一次（73 秒）勝過寫完再回頭改。視覺 QA loop（pptx）、xlsx recalc.py、reportlab unicode 上下標陷阱這些 gotchas 靠猜不可能寫出來。
- **「失敗時的依賴提示」對照表是輕量但高 ROI 的 UX 改善**：不維護完整安裝指令（會過期），只解析錯誤訊息片段並指向 sub-skill 自身文件。本次 4 個 phase prompt（xlsx/docx/pdf/pptx）皆已加上。
- **WebSearch 實測一個 query 同時做驗證 + 研究 + 內容更正**：Q1 一次查詢就推翻原 reference 的 0.495 → 實際 113 年度 0.474，順便取得 2025/2030 目標。Check 階段的最小驗證可以同時產生實質研究價值。
- **Check 階段「實機驗證」可以 DEFER 到端到端試做**：避免重複工。但必須在 task 文件裡明確標 DEFERRED + 移交目標 task（本次移到 SP1-004），不能僅跳過。
