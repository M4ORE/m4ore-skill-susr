## Act

### Lessons Learned
- **Skill frontmatter 慣例**：本專案環境的既有 skill（`design-first-development`、`production-mgmt`）皆不使用 `allowed-tools`，僅用 `name` + 多行 `description`（含 Trigger / Non-trigger 雙列）。後續所有 skill 開發應沿用此慣例。
- **Trigger / Non-trigger 雙列法**：明確列出「不觸發」情境可有效避免過度觸發（測試結果：「幫我寫 README.md」未誤觸發）。
- **8-Phase × 4 段式（Objective / Key Activities / Output / Integration）的結構**：在 ≤200 行內可完整表達 SOP，剩餘細節推到 references/，token 經濟有效。
