## Act

### Lessons Learned
- **大批並行（3 WebSearch + 4 Write + 2 Edit = 9 工具呼叫一輪）很有效率**：Claude 並行處理 WebSearch 結果沒問題，省下大量等待時間。對「資料蒐集 + 檔案產出」這類 batch 任務值得當作預設模式。
- **WebSearch 副產品比預期豐富**：Q2 拿到 11 個特定產業清單、Q3 拿到 28%/35%/40% 確信實況統計。所有附帶發現都該被記錄，不只回答原問題 — 否則下次又要重查。
- **微小 reference 也需要驗證**：Q4 把模糊的「6 個月內」精確化成 8/31，這種精度差異對使用者實際操作影響很大；模糊敘述是品質紅旗。
- **「建議直接洽詢」是必要的 escape hatch**：不是所有問題都能查到網路答案（如 MOPS 結構化資料規格），明確記錄需人為跟進的事項，比編造模糊答案誠實也安全。
