# Definition

永續報告書（Sustainability / ESG Report）是**「把一家公司的真實ESG表現，以可驗證、可比較、可信任的方式，結構化地呈現給特定利害關係人」**。

這件事的核心原子元件有四個：

1. **資料（Data）**：原始、分散、非結構化的ESG資料（碳排、用水、廢棄物、人權、供應鏈、治理…）。
2. **框架對應（Framework Mapping）**：必須精準對應GRI、SASB、TCFD、ISSB、CSRD、台灣永續報告書指引、香港ESG守則…等多個標準。
3. **敘事與判斷（Narrative + Judgment）**：把冰冷的數字轉成有策略意義的故事，並做出「雙重重大性評估」、風險揭露、目標設定等需要人類脈絡理解的判斷。
4. **信任與驗證（Assurance & Trust）**：最終報告必須能通過第三方確信（assurance）、投資人審查、監管檢查。

## Co-pilot vs Replacement 的真實差異

| 面向 | Co-pilot（建議） | Replacement（不建議） |
| --- | --- | --- |
| **目標客戶** | 輔導顧問 / ESG顧問公司 | 企業（尤其是想省錢的中小企業） |
| **商業模式** | SaaS訂閱（顧問公司每月付費） | 按報告計價或企業訂閱 |
| **顧問的反應** | 視為幫手，願意推廣 | 視為威脅，會抵制或公開批評 |
| **產品護城河** | 顧問的專業知識 + AI = 混合智能 | 純AI，容易被其他LLM追上 |
| **法律風險** | 低（最終決策仍在人類手上） | 高（幻覺、責任歸屬問題） |
| **市場規模** | 全球數萬家ESG顧問公司 + 顧問團隊 | 數百萬家需要報告的企業 |
| **產品定位** | 「顧問的第二大腦」 | 「企業的自動報告機」 |
