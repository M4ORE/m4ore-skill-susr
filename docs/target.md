# Target-要Build什麼？

**目標：**AI輔助生成永續報告書

**對象：**顧問

**產品本質**：一個**讓顧問能把「資料輸入 → 框架對應 → 初稿生成 → 專業審核」** 的時間，從原本的**40-80小時**壓縮到**8-15小時**的工具。

**核心價值主張（Value Proposition）**：
「用我們工具的顧問，能在同樣時間內產出**品質更高、框架更完整、故事更動人**的永續報告書，同時保留100%專業判斷與最終責任。」

⇒ 讓顧問變得更強、更快、能接更多案子、或做出更高品質的報告

⇒ 我們要Build的不是「自動寫報告的機器」，而是「顧問的AI超能力放大器」 —— Co-pilot，而不是Replacement。
