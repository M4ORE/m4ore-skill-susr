# GHG Protocol 計算原則與盤查指引

**使用時機**：Phase 4 數據工程（Scope 1/2/3 盤查）、Phase 5 撰寫氣候章節時 confirm 計算邏輯、Phase 7 確信前 self-check。

**主要參考**：GHG Protocol Corporate Standard、Scope 2 Guidance、Corporate Value Chain (Scope 3) Standard、ISO 14064-1。

---

## 1. 組織邊界（Organizational Boundary）

選擇一種並全程一致：

| 方法 | 適用情境 | 邊界規則 |
|------|---------|---------|
| 股權法（Equity Share） | 股權複雜、合資公司多 | 按股權比例計入 |
| 財務控制（Financial Control） | 財報編製主體一致 | 控制者 100% 計入 |
| 營運控制（Operational Control） | 營運獨立性高 | 營運主導者 100% 計入（最常採用） |

**揭露要求**：說明選擇方法、邊界內主要實體、過去三年是否變更。

## 2. 範疇一（Scope 1）— 直接排放

公司擁有或控制源的溫室氣體排放：

| 類別 | 範例 |
|------|------|
| 固定燃燒 | 鍋爐、發電機、加熱爐 |
| 移動燃燒 | 自有車隊、堆高機 |
| 製程排放 | 水泥煅燒、半導體 PFC、鋼鐵 |
| 逸散排放 | 冷媒洩漏、SF₆、瓦斯管線 |

**七種溫室氣體**（《京都議定書》）：CO₂、CH₄、N₂O、HFCs、PFCs、SF₆、NF₃

**換算**：每種氣體 × GWP（用 IPCC AR6 100 年值）= CO₂ 當量（CO₂e）

## 3. 範疇二（Scope 2）— 能源間接排放

外購電力、熱、蒸汽、冷氣的隱含排放。**雙重報告**：

| 方法 | 用因子 | 適用 |
|------|-------|------|
| 地點基礎 | 電網平均排放係數 | 反映實際物理排放 |
| 市場基礎 | 合約電力（PPA、RE100、綠電憑證）係數 | 反映採購選擇 |

**台灣電力係數來源**：
- 經濟部能源署「電力排碳係數」公告（年度更新）
- **113 年度（2024 年度）公告值：0.474 kgCO₂e/度**（公用售電業總銷售電量基準，扣除線損承擔）
- **法定下降目標**：2025 年 0.388 / 2030 年 0.319 kgCO₂e/度
- 確認來源（2026-04-29 SP1-003 / 2026-04-30 SP1-008）：
  - https://www.moeaea.gov.tw/ecw/populace/content/ContentDesc.aspx?menu_id=26678
  - https://law.moea.gov.tw/LawContent.aspx?id=GL001356（114 年電力排碳係數基準）
- 歷年值（用於基線重述比對）：111 年度 ≈ 0.494 / 112 年度 / 113 年度 = 0.474（呈下降趨勢，反映綠能占比提高）

**RE100 / 綠電採購**：採購憑證（T-REC）需符合 GHG Protocol Scope 2 Quality Criteria。

## 4. 範疇三（Scope 3）— 其他間接排放（15 類）

### 上游（1–8）

| Cat | 名稱 | 重點 |
|-----|------|------|
| 1 | 採購商品與服務 | 通常最大類別，可用支出 × EEIO 因子或實物 × LCA |
| 2 | 資本財 | 設備、基建、IT 硬體 |
| 3 | 燃料與能源相關（範疇 1/2 未涵蓋） | 燃料上游萃取、輸電損失 |
| 4 | 上游運輸與配送 | 採購端物流 |
| 5 | 營運廢棄物 | 焚化、掩埋、回收 |
| 6 | 商務旅行 | 飛機、高鐵、租車、住宿 |
| 7 | 員工通勤 | 含居家辦公能源（建議揭露） |
| 8 | 上游租賃資產 | 公司承租但非控制源 |

### 下游（9–15）

| Cat | 名稱 | 重點 |
|-----|------|------|
| 9 | 下游運輸與配送 | 銷售端物流 |
| 10 | 售出產品的加工 | B2B 製造業必估 |
| 11 | 售出產品的使用 | **耐久消費品 / 燃料 / 半導體用電 — 通常極大** |
| 12 | 售出產品報廢處理 | EoL 處理 |
| 13 | 下游租賃資產 | 公司租出 |
| 14 | 加盟通路 | 加盟主營運排放 |
| 15 | 投資 | **金融業核心，含 PCAF 方法論** |

### Scope 3 重大性篩選（建議流程）

1. 對 15 類做初步估算（screening）
2. 識別貢獻 > 5% 或合計 > 80% 的類別 → 詳細盤查
3. 揭露納入 / 排除類別與理由
4. 不可一律省略，至少識別前 5 類重大類別

## 5. 排放因子來源優先序

| 優先序 | 來源 | 適用 |
|-------|------|------|
| 1 | 供應商實測（primary data） | 大宗採購、長期合作 |
| 2 | 環境部「產品碳足跡資訊網」 | 台灣本土產品 |
| 3 | 國際資料庫（ecoinvent、GaBi、IDEMAT） | LCA 計算 |
| 4 | 國家因子（IEA、DEFRA、EPA） | 一般計算 |
| 5 | 業界估算（EEIO） | 篩選與初步估算 |

**版本控制**：每個因子標註來源、版本年度、發布單位。年度更新需重述（restate）歷史值或揭露差異。

## 6. 強度指標（Intensity Metrics）

至少揭露 1–2 種，建議：

| 指標 | 適用 |
|------|------|
| tCO₂e / 百萬營收 | 通用 |
| tCO₂e / 員工數 | 服務業 |
| tCO₂e / 產品單位（如：kg / pc / GB） | 製造業、半導體 |
| tCO₂e / 樓地板面積 | 不動產業 |

## 7. 基線重述（Baseline Restatement）

觸發條件（任一）：
- 結構性變動（併購、出售、業務重整）
- 計算方法論修訂
- 數據錯誤修正
- 排放因子重大更新

**閾值**：歷史年度值變動 > 5% → 必須重述前 ≥ 3 年數據並揭露原因。

## 8. SBTi 對應

| 路徑 | 升溫情境 | Scope 1+2 減量速率 |
|------|---------|-------------------|
| 1.5°C | 1.5°C | 4.2% / 年（絕對減量） |
| Well-below 2°C | < 2°C | 2.5% / 年 |
| 2°C | 2°C | 1.23% / 年（已不被 SBTi 接受） |

**Scope 3 要求**：若 Scope 3 > 40% 總排放，必須設定 Scope 3 目標（覆蓋至少 67% 排放）。

**Net-Zero Standard**：2050 年前達淨零，含長期目標（深度減量 ≥ 90%）+ 中和殘餘排放（持久移除）。

## 9. 確信前 self-check

- [ ] 邊界定義文件齊備（含子公司清單與權重）
- [ ] 排放源清冊（site-by-site）

- [ ] 排放因子版本與來源紀錄
- [ ] 計算底稿（Excel 或工具輸出）可重現
- [ ] 範疇三類別納入 / 排除理由
- [ ] 過去三年數據可比性（一致邊界與方法）
