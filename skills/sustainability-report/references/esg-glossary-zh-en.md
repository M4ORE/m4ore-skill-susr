# ESG 雙語術語表（zh-TW / EN）

**使用時機**：起草任何章節前 confirm 術語、跨章節 review 一致性、譯名爭議時的最終裁決。

## 核心概念

| 繁體中文 | English | 定義摘要 |
|---------|---------|---------|
| 雙重重大性 | Double Materiality | 同時評估 Impact Materiality（公司對外影響）與 Financial Materiality（議題對公司財務的風險與機會） |
| 影響重大性 | Impact Materiality | 公司活動對環境、社會、經濟的正負面影響的嚴重度與範圍 |
| 財務重大性 | Financial Materiality | 永續議題對公司財務表現、現金流、估值、資本成本的影響 |
| 利害關係人議合 | Stakeholder Engagement | 系統性辨識、聆聽、回應利害關係人關切的過程 |
| 重大性矩陣 | Materiality Matrix | 議題依雙軸（影響 × 財務）排序的視覺化結果 |
| IRO | Impact, Risk and Opportunity | ESRS 用語：每個重大議題必揭露的三維度 |
| 連結性 | Connectivity | IRO → 治理 → 策略 → 行動 → 目標 → KPI 的首尾貫通 |
| 反綠色洗白 | Anti-Greenwashing | 避免揭露失真、誇大、選擇性報告好消息 |

|---------|---------|------------|

| SASB | Sustainability Accounting Standards Board | 產業別揭露準則（已併入 ISSB） |
| SBTi | Science Based Targets initiative | 科學基礎減量目標倡議 |
| SBTN | Science Based Targets for Nature | 自然科學基礎目標 |
| CDP | Carbon Disclosure Project | 投資人主導的揭露平台 |

## 氣候與排放

| 繁體中文 | English | 定義 |
|---------|---------|------|
| 範疇一 / 直接排放 | Scope 1 / Direct emissions | 自有或控制源的溫室氣體排放 |
| 範疇二 / 能源間接排放 | Scope 2 / Energy indirect emissions | 外購電力、熱、蒸汽的排放 |
| 範疇三 / 其他間接排放 | Scope 3 / Other indirect emissions | 價值鏈上下游 15 類排放 |
| 地點基礎 | Location-based | Scope 2 用電網平均排放因子 |
| 市場基礎 | Market-based | Scope 2 採用合約電力（如 RE100 採購）排放因子 |
| 排放因子 | Emission Factor | 單位活動量轉換為 CO₂e 的係數 |
| 全球暖化潛勢 | GWP (Global Warming Potential) | 各種溫室氣體相對 CO₂ 的暖化效果 |
| 強度指標 | Intensity Metric | 單位營收 / 員工 / 產品的排放量 |
| 基線重述 | Baseline Restatement | 因併購、邊界變更、方法論修訂而重新計算歷史值 |
| 轉型計劃 | Transition Plan | 達成淨零的具體路徑、里程碑、資本配置 |
| 情境分析 | Scenario Analysis | 1.5°C / 2°C / 4°C 等氣候情境下的財務影響評估 |
| 淨零 | Net Zero | 排放等於移除，全球升溫限制在 1.5°C |
| 碳中和 | Carbon Neutral | 排放與抵換相抵（範疇與認證標準較寬鬆） |

## 用詞一致性規則

1. **範疇 vs 範圍**：GHG Protocol 用「範疇」（Scope），不用「範圍」
2. **重大性 vs 重要性**：Materiality 一律譯「重大性」
3. **利害關係人 vs 持份者**：台灣使用「利害關係人」，香港用「持份者」
4. **首次出現英文加註**：專業術語首次出現以「中文（English）」格式呈現
5. **不混用**：同一份報告中，同一概念只用一種譯名
