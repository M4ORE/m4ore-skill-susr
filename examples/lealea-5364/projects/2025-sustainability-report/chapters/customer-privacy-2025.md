# 第 5.2 章 — 顧客隱私與資訊安全

> **對應重大議題**：S7 客戶隱私（核心象限 Financial ≥4.0） + G4 資訊安全
> **適用標準**：GRI 418 客戶隱私 + ISO 27001 + 個人資料保護法 + 觀光產業實務指引
> **章節公式**：IRO → 治理 → 策略 → 行動 → 目標 → KPI → 展望

---

## 1. IRO（Impact / Risk / Opportunity）

### 1.1 衝擊（Impact）

旅館業是 **PII 密集行業**：每筆訂房含姓名 / 身分證字號 / 信用卡 / 聯絡資訊 / 旅伴關係 / 飲食偏好 / 健康狀況（過敏原）等。會員制更聚積多年消費行為與位置軌跡。一筆資料外洩衝擊：個人隱私 + 信任 + 潛在被詐騙風險。

### 1.2 風險（Risk）— 引用 IRO entity

對應 `entities/iros/S7-customer-privacy-risk-leak.md`：

| 子類 | 說明 | 時間框架 | 財務影響 |
|---|---|---|---|
| 法規罰款 | 個資法第 47 條，最高 NTD 2,000 萬/件 | 短期 | 高額罰款 |
| 集體訴訟 | 大規模洩漏可能引發消費者集體訴訟 | 中期 | 賠償金 + 法律費用 |
| 商譽崩潰 | 國際商務客 / 高端會員流失 | 短期 → 中期 | 訂房率、會員 retention |
| 信用卡濫用 | PCI-DSS 違規 → 卡片網絡罰款 + 終止合作 | 短期 | 收款管道喪失 |

**旅館業特殊**：監控影像 + 房卡使用紀錄 + Wi-Fi 連線紀錄都是個資；員工流動率高，內部濫用風險不低。

### 1.3 機會（Opportunity）

1. **ISO 27001 認證行銷**：旅館業普及率低，取得認證可作為高端商務 / 國際客的差異化定位
2. **會員資料管理透明化**：明確說明資料使用目的 + opt-in 機制 → 反向強化品牌信任
3. **資安投入 ROI**：阻擋一次重大事件節省 NTD [X] 千萬，遠超系統建置成本

## 2. 治理（Governance）

- **主責**：IT 部主管 + 法務（個資法 / GDPR / CCPA 對應）
- **監督**：永續委員會「資訊安全」分組（如未獨立分組則由治理結構分組覆蓋），每季 review
- **執行頻率**：資安內部稽核每月、外部滲透測試每年；資安事件 4 小時內報集團
- **董事會 KPI 連動**：資訊長績效考核含資安事件嚴重度（單件 critical 事件 = 年度扣 [N]%）

---

## 3. 策略（Strategy）

旅館業資安不是「跟 IT 公司一樣」，而是要對應**多點接觸的 PII 流**：

1. **資料最小化層**：訂房 / 入住流程只收集必要欄位，避免「為以後可能用而蒐集」
2. **存取控制層**：員工帳號最小權限 + 多因子驗證 + 監控異常存取
3. **加密層**：傳輸 TLS 1.3 + 儲存加密 + 信用卡 token 化（PCI-DSS）
4. **回應層**：資安事件 SOP（4 小時通報主管機關 + 7 日通報受影響客戶 + 30 日內根因分析 + 補救）

## 7. 展望與誠實揭露

### 2024 未達標項

依力麗 2023 報告書（_legacy/phase7-gap-analysis §1），原版**僅 GRI 418 列入 Index、無獨立章節揭露**。試做 2025 升級包含：
- 資安事件分嚴重度逐件揭露
- 個資主體權利請求數量 / 回覆時間揭露（GDPR / 個資法）
- 監控影像與 Wi-Fi 紀錄保存期限政策明文揭露

### 改善路徑

- **2025**：完成 PII 盤點、ISO 27001 試點申請
- **2026**：ISO 27001 認證至少 1 處；國際監管對應（GDPR / CCPA）完整化
- **2027**：擴展認證至全據點；考慮 PCI-DSS L1 認證（高端會員消費密度提升時）
