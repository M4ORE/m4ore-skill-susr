# 第 6.1 章 — 在地共融與文化保存

> **對應重大議題**：S10 在地僱用 + S12 文化保存與原民共榮（重大象限，SP1-004 旅館業特化納入）
> **適用標準**：GRI 411 原住民權利 + GRI 413 在地社區 + SASB SV-HL-310a.1 + 原住民族基本法
> **章節公式**：IRO → 治理 → 策略 → 行動 → 目標 → KPI → 展望

## 1. IRO（Impact / Risk / Opportunity）

### 1.1 衝擊（Impact）— 引用 IRO entity

對應 `entities/iros/S12-indigenous-culture-impact-preservation.md` + `S10-local-employment-impact-economy.md`：

**馬告生態園區與泰雅族部落**：力麗明池、棲蘭兩處據點位於宜蘭縣大同鄉，鄰近泰雅族傳統領域與部落（南山、四季、英士等）。旅館營運直接影響：

1. **文化保存衝擊**：營運中**呈現 / 包裝 / 傳承**部落文化的方式，會塑造遊客對泰雅族的認知（正向或扁平化）
2. **在地經濟衝擊**：當地僱用比例、在地採購、稅收貢獻直接影響部落經濟與年輕人留鄉意願
3. **生態 / 土地衝擊**：部落視自然為祖靈領域，旅館營運的環境足跡涉及文化敏感性

### 1.2 風險（Risk）

| 子類 | 說明 | 時間框架 | 財務影響 |
|---|---|---|---|
| 社會許可 | 對部落不尊重 → 社會抗議 / 媒體曝光 / 「明池營運社會許可」喪失 | 中期 | 營運中斷 / 商譽 |
| 文化扁平化 | 把原民文化包裝為觀光「秀」而非平等共榮 → 反向受抨擊 | 中期 | 品牌定位 |
| 在地關係 | 僅商業交易、無深度連結 → 在地年輕人流失 → 缺工 | 長期 | 人力短缺、營運成本 |

### 1.3 機會（Opportunity）

1. **差異化體驗**：與部落合作的原民文化深度旅遊（語言、織布、狩獵故事、生態知識）— 與一般山區度假村區隔
2. **在地創生品牌**：明池作為地方創生案例 → 政府補助、媒體曝光、政策影響力
3. **永續觀光標的**：對接國際永續觀光認證（GSTC、Travelife）

---

## 2. 治理（Governance）

- **主責**：永續發展辦公室「在地共融」專案小組 + 明池 / 棲蘭店長
- **監督**：永續委員會每年至少 1 次「在地共融年度議合會議」（與部落代表、地方政府、NGO）
- **執行頻率**：與部落合作之承諾每季 review；爭議事件 24 小時內升級至集團
- **董事會 KPI 連動**：在地共融項目納入 ESG 加分項

---

## 3. 策略（Strategy）

從「友善鄰居」升級為「共榮夥伴」的三層策略：

1. **諮詢層（Consent）**：所有涉及原民文化內容的營運決策（活動、餐點、行銷文宣）事前與部落代表諮詢
2. **共創層（Co-create）**：與部落共同設計文化體驗（**部落 own 內容、力麗 own 通路**），收益分配對等
3. **培力層（Capacity building）**：在地僱用優先、青年培訓計畫、與部落學校 / 教會合作

⚠️ **明確不做**：
- 把部落圖騰當「裝飾」用
- 不諮詢就採用部落語言 / 儀式作為行銷素材
- 將部落呈現為「觀光景點背景」

## 7. 展望與誠實揭露

### 2023-2024 揭露不足項

依力麗 2023 報告書（_legacy/phase3-materiality.md S12 段、_legacy/phase7-gap-analysis §2.2），原版**未將原民共融列為重大議題**、**未深度揭露明池對泰雅族部落的關係**。試做 2025 主動納入，並承認：

- 在地僱用比例與部落採購基線數據仍待補完
- 過去文化體驗以「示範表演」為主，**尚未實現 co-create 模式**
- 缺乏制度化的部落諮詢機制

### 改善路徑

- **2025**：制度化議合會議 + 啟動 co-create pilot + 在地僱用招募活動
- **2026**：完成 GSTC 試點認證 + 部落 co-create 內容擴展
- **2027-**：明池作為「企業 + 部落共榮」標桿案例 → 對接政府地方創生政策、申請國際永續觀光認證

### 與三原則對齊

本章呼應 CLAUDE.md §0「susr 是顧問為顧問而設」設計哲學 — 旅館業常忽略的「**文化敏感性**」議題正是顧問判斷的核心戰場，brain 提供 entity 結構讓顧問追蹤承諾，但 **co-create 的真實對等關係只有顧問與部落共同建構**。
