# G3 法令遵循風險：違規罰款 / 停業

## 來源

萃自 `_legacy/phase3-materiality.md` §6 表（G3 列）：

> G3 法令遵循 | I：合規；R：違規罰款 / 停業；O：合規強化內控 | 法令遵循

並對照 §3 議題池 G3 旅館業特殊性：

> 觀光發展條例、食品衛生、消防、勞基法

## 描述（Risk 主軸）

旅館業適用法令密度極高：

1. **觀光發展條例** — 旅宿業登記 / 廣告不實 / 接待外國旅客；
2. **食品衛生** — 已於 S6 處理；
3. **消防法** — 山區據點消防距離 / 自動撒水系統；
4. **勞基法** — 已於 S1 處理；
5. **個資法** — 已於 S7 處理。

違規後果：罰款 + 停業處分（消防 / 食品 / 旅宿登記）。機會面：合規強化內控反向促進管理品質。

## 時間框架

短期（1-3y）— 主管機關不定期稽查，違規隨時爆發。
