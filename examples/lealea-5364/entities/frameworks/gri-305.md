# GRI 305 — Emissions

**發行機構**：Global Reporting Initiative (GRI)
**領域**：環境（Environment）
**首次發布**：2016 年，2021 Universal Standards 升版後仍為核心 Topic Standard。

## 範圍

GRI 305 揭露組織溫室氣體（GHG）排放量、排放強度與減量成效。為氣候揭露的核心 GRI 主題標準，與 TCFD / ISSB IFRS S2 形成「廣度（GRI）+ 深度（TCFD/ISSB）」互補揭露。

## 主要揭露

- **305-1**：Scope 1 直接排放（自有 / 控制排放源）。
- **305-2**：Scope 2 能源間接排放（外購電力 / 蒸汽 / 熱）。
- **305-3**：Scope 3 其他間接排放（供應鏈 / 通勤 / 廢棄物 / 委外房務）。
- **305-4**：排放強度（tCO2e / 住房數）。
