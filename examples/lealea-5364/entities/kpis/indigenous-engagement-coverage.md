# KPI: 在地原住民議合覆蓋率

## 定義

馬告生態園區範圍內，明池 / 棲蘭兩館鄰近的泰雅族部落，已進行年度議合（部落會議出席 +
回饋機制 + 共創合作）的部落數 ÷ 總部落數。

## 揭露要素

- 已議合部落清單（含部落會議出席紀錄）
- 議合議題清單（土地使用 / 文化保存 / 在地就業 / 採購）
- 回饋與爭議處理機制
- 共創 / 經濟效益分潤合約存在與否

## 旅館業特化

馬告生態園區位於原住民傳統領域 → 觸發 GRI 411-1（原住民權利）與 GRI 413-2
（負面衝擊評估）強制揭露。**SP1-004 試做特化**：旅館業常忽略此議題。
