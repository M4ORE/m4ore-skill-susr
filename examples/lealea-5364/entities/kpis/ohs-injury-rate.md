# KPI: FR / SR / 千人率

## 計算公式

```
FR = 失能傷害次數 × 1,000,000 / 工時
SR = 失能傷害日數 × 1,000,000 / 工時
千人率 = 失能傷害次數 × 1000 / 人數
```

## 旅館業特化

- 餐飲燙傷 / 房務肌肉骨骼 / 夜班疲勞 三大職業病分類
- 夜班人數獨立追蹤
