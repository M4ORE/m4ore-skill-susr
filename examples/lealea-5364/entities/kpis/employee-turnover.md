# KPI: 員工流動率

## 定義

依 GRI 401-1，按性別、年齡、地區分組。

## 旅館業基準

業界流動率 30%+；目標應顯著低於業界。

## 計算公式

```
流動率 = 期內離職人數 / 期初人數
```
