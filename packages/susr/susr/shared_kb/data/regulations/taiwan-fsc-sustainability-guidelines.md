# 台灣金管會永續報告書指引

**使用時機**：Phase 1 確認適用標準、Phase 5 撰寫法定章節（誠信經營、利害關係人議合、氣候揭露）、Phase 8 公告前確認時程符合。

**注意**：本文件以 2026-04-30 已知資訊為準（部分項目經 SP1-008 WebSearch 驗證）。任何「最新版本」「下半年公告」相關判斷，請走 Phase 2 WebSearch 至金管會 / 證交所 / 櫃買中心官網確認。

## 1. 主要法源與指引

| 文件 | 發布單位 | 性質 |
|------|---------|------|
| 上市上櫃公司編製與申報永續報告書作業辦法 | 金管會 / 證交所 / 櫃買中心 | 強制 |
| 上市上櫃公司永續發展實務守則 | TWSE / TPEx | 自律 |
| 上市公司編製氣候相關資訊揭露指引 | TWSE / TPEx | 強制（採 TCFD/ISSB 四構面） |
| 公司治理 3.0 永續發展藍圖 | 金管會 | 政策指引 |
| 公司治理評鑑指標 | TWSE | 年度評鑑 |

## 2. 適用對象與分級

依資本額與產業，分批納入強制申報：

| 階段 | 適用對象 | 期程 |
|------|---------|------|
| 第一階段（已實施） | 資本額 ≥ 100 億 + 化學工業 + 金融保險業 | 已強制申報 |
| 第二階段 | 資本額 50–100 億 | 已實施 |
| 第三階段 | 資本額 20–50 億 | 已實施 |
| **第四階段（已實施）** | **資本額 < 20 億上市櫃公司** | **自 114 年（2025）起編製 113 年度（2024 年度）永續報告書** |

**規模判定**：以申報日前一年度公司資本額為準。

**特定產業加強揭露**（資本額 ≥ 20 億且屬下列產業，需依產業別加強揭露 ESG 指標）：
- 水泥工業、塑膠工業、鋼鐵工業、油電燃氣業
- **半導體業**、電腦及週邊設備業、光電業、通信網路業、電子零組件業、電子通路業、其他電子業

**重大里程碑**：自 2025 年起，**全體上市櫃公司均強制編製永續報告書**。

## 3. 報告書編製內容（強制章節）

依作業辦法附表，至少涵蓋：

1. **公司治理**
   - 公司組織與營運概況
   - 董事會結構、獨立性、專業背景
   - 永續委員會 / 風險管理委員會
   - **誠信經營**（強制專章，含反貪政策、教育訓練、申訴管道）
   - 風險管理機制（含 ESG 風險）

2. **環境永續**
   - 溫室氣體盤查（範疇 1/2 強制，範疇 3 漸進納入）
   - 能源、水、廢棄物管理
   - **氣候相關財務揭露（TCFD/ISSB 四構面）強制**
   - 生物多樣性（依產業適用）

3. **社會共融**
   - 員工結構、健康安全、教育訓練、人權
   - 供應鏈管理
   - 客戶關係與產品責任
   - 社會公益

4. **利害關係人議合**（強制專章）
   - 利害關係人辨識（至少七類：股東、員工、客戶、供應商、政府、社區、媒體）
   - 溝通管道與頻率
   - 關注議題與回應

5. **重大性鑑別過程**
   - 議題池、評分、矩陣、董事會核准

6. **附錄**
   - GRI Content Index
   - SASB / TCFD / ISSB 對照表
   - 第三方確信報告（如有）

## 4. 採用準則組合（建議）

主流選擇（覆蓋率最高）：

```
GRI Universal Standards 2021（基礎框架）
+ ISSB IFRS S1（一般要求）
+ ISSB IFRS S2（氣候）
+ SASB 產業別指標（透過 ISSB 整合）
+ 台灣金管會作業辦法 + TWSE 氣候揭露指引
```

如有歐盟業務或外資投資者比例高，加採：
```
+ ESRS（CSRD 要求）
```

## 5. 第三方確信要求

依規模與產業分級強制：

| 公司類型 | 確信要求 |
|---------|---------|
| **食品工業**（餐飲收入占總營收 ≥ 50%） | **強制取得會計師確信** |
| **金融保險業** | **強制取得會計師確信** |
| 部分大型上市櫃（依資本額分級） | 限定確信（Limited Assurance） |
| 全體適用對象 | 金管會 2024 年研議擴大強制對象，漸進推進中 |

**確信標準**：
- **ISAE 3000**（International Standard on Assurance Engagements 3000）— 會計師確信主流標準
- AA1000AS v3 — 第三方驗證機構常用
- 中華民國會計研究發展基金會準則

**2023 年永續報告書確信現況**（截至 2024 年發行的 1,064 家公司）：
- 28.29% 取得會計師確信
- 34.77% 取得第三方驗證確信
- 40.13% 尚未取得任何確信

**趨勢**：金管會方向為漸進擴大強制對象，建議大型 / 上市掛牌公司提早佈局。

## 6. 公告與報送時程

| 時點 | 動作 |
|------|------|
| 年度結算後 | 開始編製 |
| 約 5–7 個月內 | 報告書定稿 + 內部簽核 |
| **每年 8 月 31 日（含）前** | **正式申報期限**（依 2025 年 5 月 TWSE 更新之作業辦法） |
| 申報 | 上傳 MOPS（公開資訊觀測站） + 公司官網 |
| 後續 | 利害關係人發布、董事會報告 |

**重要更新**：2025 年 5 月 TWSE 修訂「上市公司編製與申報永續報告書作業辦法」，**申報期限統一為 8/31**。逾期影響公司治理評鑑。

**雙語版本**：未強制要求，但實務上外資比例高、海外掛牌、金融保險業多自願出英文版以利國際投資人閱讀。

**MOPS 結構化資料規格**：細節以 TWSE / TPEx「永續報告書專區」最新公告為準（建議直接洽詢）。

## 7. MOPS 公告流程

1. 報告書定稿並經董事會通過（建議納入年度議程）
2. 登入 MOPS（mops.twse.com.tw）→ 永續報告書專區
3. 上傳 PDF + 必要的結構化資料
4. 公告後不可隨意撤換；如需更正應發重大訊息

## 8. 公司治理評鑑連動

TWSE 公司治理評鑑指標含永續報告書相關項目：

- 是否依時公告
- 是否取得第三方確信
- 是否揭露董事會 ESG 監督機制
- 是否揭露氣候相關財務資訊

評鑑結果分級（Top 5%、6%–20%、21%–35%、36%–50%、後 50%）影響法人持股意願。

## 9. 常見痛點與解決建議

| 痛點 | 常見錯誤 | 建議解法 |
|------|---------|---------|
| 範疇三遺漏 | 只報外購電力、商務旅行 | Phase 4 做 15 類 screening，至少揭露前 5 大類別 |
| 目標無基線 | 「2030 減碳 30%」沒說基準年 | 每個目標必含基線年 + 目標年 + 達成路徑 |
| 董事會專業揭露不足 | 只列董事姓名 | 個別揭露氣候 / 數位 / 治理專業背景 |
| 誠信經營流於表面 | 政策聲明後無 KPI | 揭露教育訓練時數、申訴案件數、處理結果 |
| 利害關係人議合形式化 | 列七類但無實質議題 | 揭露議合方法、頻率、關鍵議題、回應 |
| 雙語不一致 | 中英版本內容有差異 | 以一版為主版，另一版翻譯後反查校對 |
| 抄前一年 | 內容更新極少 | YoY 比較專章，揭露重大變化原因 |

## 10. 海外掛牌與 ADR 公司

- 美國上市：SEC Climate Disclosure Rule（如已實施）
- 歐盟業務 / 子公司 → CSRD + ESRS
- 香港上市：HKEx ESG Reporting Guide
- **整合策略**：以最嚴標準編製主版，其他版本作映射
