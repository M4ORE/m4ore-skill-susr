# 永續報告書合規檢查清單

**使用時機**：Phase 7 Review 階段逐項過、Phase 6 組裝前 self-review、Phase 1 確認適用範圍時參考。

**適用標準組合**：GRI Universal 2021 + ISSB IFRS S1/S2 + 台灣金管會作業辦法。歐盟 ESRS 另有獨立映射表（待擴充）。

---

## A. 治理（Governance）— 8 項

- [ ] A1 董事會對永續議題的監督機制揭露（頻率、議題範圍、KPI）
- [ ] A2 永續委員會 / 風險委員會組成與運作
- [ ] A3 董事會 ESG 專業背景揭露（個別董事的氣候 / 社會 / 治理專業）
- [ ] A4 高階主管薪酬與 ESG 績效連結（含具體 KPI 與權重）
- [ ] A5 永續長（CSO）或對應職能的權責與彙報層級
- [ ] A6 內控與內稽涵蓋 ESG 議題
- [ ] A7 利益衝突與關係人交易揭露
- [ ] A8 吹哨者 / 檢舉管道與不報復承諾

## B. 策略（Strategy）— 6 項

- [ ] B1 公司願景、使命、永續策略的整合性敘述
- [ ] B2 重大議題對商業模式的影響（短 / 中 / 長期）
- [ ] B3 氣候情境分析（至少 1.5°C 與 2°C 兩情境）
- [ ] B4 轉型計劃（含里程碑、資本配置、技術依賴）
- [ ] B5 機會面揭露（不只風險，含綠色商機、創新、效率）
- [ ] B6 對產品 / 服務組合的永續性評估

## C. 風險管理（Risk Management）— 5 項

- [ ] C1 永續風險辨識流程（與企業整體風險管理整合）
- [ ] C2 TCFD / ISSB 四構面：實體風險、轉型風險、機會
- [ ] C3 主要風險的時間軸（短 / 中 / 長期）與財務量化
- [ ] C4 風險減緩措施與資源投入
- [ ] C5 供應鏈風險評估與盡職調查

## D. 指標與目標（Metrics & Targets）— 7 項

- [ ] D1 範疇一、範疇二（地點與市場基礎）排放量
- [ ] D2 範疇三主要類別揭露（建議至少 5 類重大類別）
- [ ] D3 排放強度指標（每營收 / 每產品）
- [ ] D4 SBTi 認證或對應的科學基礎目標
- [ ] D5 每個目標含基線年、目標年、達成時程
- [ ] D6 進度揭露（往年 vs 本年 vs 目標的差距分析）
- [ ] D7 未達標項目的原因說明與修正計劃

## E. 重大性評估（Materiality）— 5 項

- [ ] E1 雙重重大性方法論揭露（評分軸、權重、閾值）
- [ ] E2 利害關係人盤點與議合過程
- [ ] E3 重大議題清單（含與前年比較的變動原因）
- [ ] E4 重大性矩陣或排序圖
- [ ] E5 董事會 / 永續委員會核准紀錄

## F. GRI Universal 2021 必揭露項目 — 12 項

- [ ] F1 GRI 2-1 組織概況
- [ ] F2 GRI 2-2 報告組織邊界
- [ ] F3 GRI 2-3 報告期間 / 頻率 / 聯絡窗口
- [ ] F4 GRI 2-4 資訊重述
- [ ] F5 GRI 2-5 外部確信
- [ ] F6 GRI 2-9 治理結構與組成
- [ ] F7 GRI 2-12 ~ 2-14 董事會永續監督
- [ ] F8 GRI 2-22 永續發展策略聲明
- [ ] F9 GRI 2-23 政策承諾
- [ ] F10 GRI 2-26 ~ 2-27 道德管道與遵循狀況
- [ ] F11 GRI 2-29 利害關係人議合方法
- [ ] F12 GRI 3-1 ~ 3-3 重大議題管理方針

## G. ISSB / TCFD 揭露 — 4 構面

- [ ] G1 治理（Governance）— 董事會與管理階層對氣候議題的角色
- [ ] G2 策略（Strategy）— 氣候對業務的影響與韌性
- [ ] G3 風險管理（Risk Management）— 氣候風險辨識、評估、管理流程
- [ ] G4 指標與目標（Metrics & Targets）— 含 Scope 1/2/3 與目標進度

## H. 台灣金管會特定要求 — 6 項

- [ ] H1 誠信經營（公司治理章節，含反貪、教育訓練、申訴）
- [ ] H2 利害關係人議合專章（七大類至少：股東、客戶、員工、供應商、社區、政府、媒體）
- [ ] H3 氣候相關財務揭露（依 TWSE 指引，採 TCFD/ISSB 四構面）
- [ ] H4 公司治理評鑑相關資訊
- [ ] H5 MOPS 公告時程符合（依規模分級）
- [ ] H6 中英對照版本（如海外掛牌或外資比例高）

## I. 數據品質與可追溯性 — 5 項

- [ ] I1 每個 KPI 標註計算邊界（合併 / 控制 / 股權）
- [ ] I2 每個 KPI 標註單位、計算公式、資料來源
- [ ] I3 排放因子版本與來源標註
- [ ] I4 基線重述（>5% 變動）已揭露原因
- [ ] I5 估算 vs 實測比例揭露

## J. 反綠色洗白檢查 — 5 項

- [ ] J1 揭露未達標項目（不只報好消息）
- [ ] J2 目標不靠未來不確定技術（如 CCS）撐場
- [ ] J3 抵換（offset）使用比例與品質揭露
- [ ] J4 負面事件（罰款、勞資爭議、資安）透明處理
- [ ] J5 同業比較或外部 benchmark 標註，避免片面數字

---

## 確信前置額外檢查（如委託第三方確信）

- [ ] 確信範圍與標準（ISAE 3000 / AA1000AS）已書面確認
- [ ] 確信機構獨立性聲明
- [ ] 文件清單就緒（原始數據、計算底稿、佐證憑證）
- [ ] 過往年度確信意見的修正紀錄

---

**通過標準**：A–H 任一類缺漏 ≥ 20% 視為未通過，需補件後重檢。J 類任一項未通過視為紅旗，董事會必審。
